# Project Aether

A 2D top-down hero-based shooter inspired by modern battle royale mechanics.

Project Aether is an original game project built from scratch using C++ and SFML.

## Current Status

🚧 Early Development

### v0.0.1

- Initial CMake project
- C++17 configuration
- SFML 3.0.2 integration
- Basic game loop
- First game window

## Technology

- C++17
- SFML 3.0.2
- CMake
- MinGW-w64 / GCC
- Git
